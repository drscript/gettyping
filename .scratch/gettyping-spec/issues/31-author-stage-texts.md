# 31 — Author the remaining 20 Stage Exercise texts

Type: task
Blocked by: 26
Status: done

## What to build

The lesson text for Stages 2 through 21, to the constraint Stage 1 established.

Each Stage's text is **cumulative** — drawn from every key taught in Stages 1 through *n*, weighted toward that Stage's new keys — so what was learned at Stage 2 is still being practised at Stage 12, rather than taught once and abandoned. A Stage teaches only one to three new keys, so nobody is asked to absorb a whole row at once.

The curriculum order is fixed and builds outward from the keys the fingers rest on: home row (F/J, G/H, D/K, S/L, A/;), then top row (R/U, T/Y, E/I, W/O, Q/P), then bottom row (V/N, B/M, Z/X/C), then Shift and capitalisation, then punctuation (comma and period; apostrophe, question mark, exclamation mark), then numbers paired outward from the index fingers (1/0, 2/9, 3/8, 4/7, 5/6).

Each text is **fixed once live**. Re-drawing a Stage's text would break the per-Exercise Leaderboard model, and replacing one means a new Exercise with its own board rather than an edit to the existing row.

Length should be comfortably reachable at 90% accuracy by a beginner typing slowly.

## Acceptance criteria

- [x] Every Stage from 2 to 21 has authored Exercise text.
- [x] No Stage's text contains a key not yet taught by that Stage.
- [x] Each Stage's text uses its own new keys more heavily than the keys inherited from earlier Stages.
- [x] Every Stage's text also draws on earlier keys rather than only the new ones.
- [x] The Shift Stage's text requires capitalisation, and the punctuation and number Stages exercise the characters they teach.
- [x] A test asserts the taught-keys-only constraint across all 21 Stages, rather than it being checked by inspection.
