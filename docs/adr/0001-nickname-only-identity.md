# Nickname-only identity, no accounts

Players are identified by a chosen Nickname alone — no password, no email, no signup flow. We chose this over a full account system because the target audience includes children as young as 5, for whom password management is a real barrier, and because the app stores no data valuable enough to justify the security and UX cost of authentication. The trade-off: a Nickname can't be recovered or protected if a Player's local device state is lost, and nothing stops someone else from reusing a name.
