# Leaderboards are scoped per Exercise, not global

Each Exercise has its own top-10 Leaderboard; there is no single leaderboard spanning the whole app. We chose this over one global leaderboard because Scores from a 5-year-old's first Learn Stage and an adult's Speed Test aren't comparable — a global ranking would be either meaningless or discouraging to beginners. This is a deliberate reading of "display to everyone the top 10 scores": everyone can see every Leaderboard, but no single list ranks all Players against each other.
