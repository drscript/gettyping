# GetTyping application redesign

- **Scope:** Every player-facing Svelte route and shared UI component, including the primitives showcase. Primary mode is Operate; grown-up guidance is a Read sub-surface.
- **Audience and job:** Young beginners learning at home or school choose a Track, complete typing Exercises, understand feedback, and continue progressing. Existing typists diagnose and improve weak keys through a more precise expression of the same world.
- **Primary action:** New Players choose Learn or Speed Test & Practice. Returning Players continue their next relevant activity. On task surfaces, completing the current typing Attempt is always visually dominant.
- **Content and proof:** The two-Track mechanism, 21 gated Learn Stages, Speed Test metrics, Weak-key Profile, per-Exercise Leaderboards, and browser-local Player identity are the factual material. No invented proof or commercial claims.
- **Chosen direction:** The Learning Landscape—an immersive indigo classroom opening onto flowing periwinkle paper terrain with original soft 3D schoolroom objects, tactile arched Track doors, physical stage tokens, and cooler keycap-based Speed surfaces.
- **Memorable moment:** The first viewport presents the keyboard desk landscape and two freestanding Track doors as the product's mechanism, with the Stage path and Speed Test preview emerging from the same terrain below.
- **Constraints:** Preserve routes, semantics, factual copy, keyboard behavior, focus visibility, non-color feedback, responsive operation, and all product terminology. Raster artwork may establish atmosphere but never contain core UI text or controls.
- **Unresolved decisions:** None. The approved north-star composition is `docs/design/gettyping-redesign-approved.png`.
